# Приём заявок с формы сайта (Telegram и/или e-mail)

Форма на сайте отправляет заявку не напрямую, а на облачную функцию. Функция уже
на территории РФ (дата-центры Yandex Cloud) и оттуда шлёт заявку в Telegram и/или
на почту. Секреты (токен бота, пароль почты) лежат в переменных окружения функции
и в репозиторий/код сайта не попадают.

```
Форма (браузер, РФ)
   │  POST JSON  { name, contact, type, message, consent, consent_at }
   ▼
Yandex Cloud Function  (РФ, хранит секреты)
   ├─▶ Telegram Bot API   — если задан BOT_TOKEN
   └─▶ SMTP → почтовый ящик — если задан SMTP_HOST
```

Настроить нужно **хотя бы один** канал. Можно оба.

---

## Вариант 1. Заявки на e-mail (без Яндекс Форм, в рамках 152-ФЗ)

Данные не покидают РФ: браузер → функция в Yandex Cloud (РФ) → SMTP → российский
почтовый ящик. Почтовый ящик и есть «база в РФ» для локализации.

### 1.1 Завести почтовый ящик в РФ

Любой из:
- ящик на своём домене: `zakaz@ceram8.ru` (Yandex 360 для бизнеса или почта у
  хостера домена) — выглядит солиднее;
- обычный ящик Яндекс.Почты или Mail.ru — быстрее и бесплатно.

Включите доступ по SMTP и создайте **пароль приложения** (Яндекс/Mail.ru требуют
именно его, а не основной пароль).

Параметры SMTP:
| Провайдер | SMTP_HOST | SMTP_PORT |
|-----------|-----------|-----------|
| Яндекс | `smtp.yandex.ru` | `465` |
| Mail.ru | `smtp.mail.ru` | `465` |
| Почта на домене у Beget | `smtp.beget.com` | `465` |

### 1.2 Развернуть функцию (см. раздел «Развёртывание» ниже) с переменными:

```
SMTP_HOST = smtp.yandex.ru
SMTP_PORT = 465
SMTP_USER = zakaz@ceram8.ru
SMTP_PASS = <пароль приложения>
MAIL_TO   = zakaz@ceram8.ru
ALLOW_ORIGIN = https://ceram8.ru
```

## Вариант 2. Заявки в Telegram

Мгновенное уведомление в ваш Telegram. Если это единственный канал — учтите, что
переписка Telegram хранится за пределами РФ (нюанс локализации ПДн; для маленькой
мастерской риск невелик, но для «по учебнику» лучше добавить и e-mail).

### 2.1 Создать бота

1. В Telegram напишите **@BotFather** → `/newbot` → получите **токен** `123456789:AAH...`.
2. Напишите этому боту любое сообщение — иначе он не сможет вам писать.
3. Узнайте свой **chat id**: напишите боту **@userinfobot**, он пришлёт `Id: 123456789`.

### 2.2 Переменные функции:

```
BOT_TOKEN = 123456789:AAH...
CHAT_ID   = 123456789
ALLOW_ORIGIN = https://ceram8.ru
```

Можно задать переменные и Telegram, и e-mail одновременно — заявка уйдёт по обоим.

## Развёртывание функции в Yandex Cloud

1. <https://console.yandex.cloud> → войти через Яндекс ID.
2. Нет облака — создать, привязать карту (спишется и вернётся ~1 ₽; бесплатного
   лимита хватает с запасом: 1 000 000 вызовов/мес).
3. **Cloud Functions** → **Создать функцию** → имя `ceram8-form`.
4. Вкладка **Редактор**:
   - Среда выполнения: **python312**
   - Через редактор кода: создать файл `index.py`, вставить содержимое
     [`index.py`](./index.py) из этой папки.
   - **Точка входа:** `index.handler`
   - Таймаут: `15` секунд, память: `128 МБ`.
5. Раздел **Переменные окружения** — добавить переменные из выбранного варианта выше.
6. **Сохранить изменения**.
7. Вкладка **Обзор** → включить тумблер **Публичная функция**.
8. Скопировать **ссылку для вызова** — вида
   `https://functions.yandexcloud.net/d4xxxxxxxxxxxxxxxxxx`.

## Подключение к сайту

Ссылку функции вписать в `script.js`:

```js
var FORM_ENDPOINT = "https://functions.yandexcloud.net/d4xxxxxxxxxxxxxxxxxx";
```

Пока `FORM_ENDPOINT` пустой, кнопка «Отправить заявку» открывает письмо (`mailto`)
на адрес из `MAIL_TO` в `script.js` — как запасной вариант.

## Проверка

Заполнить форму на сайте (с отметкой согласия) и отправить. В течение пары секунд
заявка придёт в Telegram и/или на почту. Функция отклоняет запросы без имени,
контакта или без согласия (`consent`).

## Смена секретов

- Токен бота: @BotFather → `/revoke` → новый токен → обновить `BOT_TOKEN` в функции.
- Пароль почты: пересоздать пароль приложения → обновить `SMTP_PASS`.

Сайт при этом трогать не нужно.
