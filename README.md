# Ceram8 — сайт гончарной мастерской

Одностраничный адаптивный лендинг. Чистый HTML + CSS + немного JS, без сборщиков,
фреймворков и внешних библиотек. Работает офлайн — достаточно открыть `index.html`
двойным щелчком.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка и весь текст сайта |
| `style.css` | Оформление, все три дизайн-концепции |
| `script.js` | Переключатель концепций, год в подвале, отправка формы |
| `images/` | Фотографии изделий и фоновые картинки |
| `PHOTO-CREDITS.md` | Источники и лицензии фоновых изображений |

## Как открыть локально

1. Скачайте папку целиком.
2. Дважды щёлкните по `index.html` — откроется в браузере, интернет не нужен.

Либо, если установлен Python, из папки проекта:

```
py -3 -m http.server 8000
```

и открыть <http://127.0.0.1:8000>.

## Переключатель дизайн-концепций

Вверху страницы — тёмная панель «Дизайн: …» с тремя кнопками. Переключение
мгновенное, без перезагрузки, выбор запоминается в браузере.

1. **Тёплый минимализм** — светлая песочно-глиняная палитра, много воздуха,
   крупные фото, спокойная типографика. На фоне всего сайта — зернистая фактура
   глины под осветляющим слоем (заметная, но не мешает тексту). Универсальный
   «продающий» вариант.
2. **Журнальный** — редакционный стиль: очень крупные заголовки, жёсткие линии,
   прямые углы, асимметричная сетка галереи, красный акцент. Смелее и заметнее.
3. **Тёмный премиум** — тёмный тёплый фон, золотой акцент, на первом экране —
   ненавязчивая затемнённая фоновая текстура (можно заменить на настоящее фото,
   см. ниже). Блок для ресторанов поднят сразу под первый экран — акцент на B2B
   и работе с заведениями.

### Когда выбор сделан

Оставлять переключатель на «боевом» сайте не нужно. Чтобы зафиксировать одну
концепцию:

1. В `index.html` в теге `<html lang="ru" data-design="1">` поставьте нужный номер
   (`1`, `2` или `3`).
2. Удалите блок `<!-- ПЕРЕКЛЮЧАТЕЛЬ ... -->` … `</div>` (весь `<div class="switcher">`).
3. В `style.css` можно удалить секцию `/* Переключатель концепций */`
   (необязательно — она просто не будет задействована).
4. В `script.js` блок переключателя тоже станет ненужным (можно оставить — ошибок нет).

## Что нужно вставить вручную

### 1. Контактные данные

Уже вписаны: ссылка на профиль Авито, город Санкт-Петербург. Телефон и Telegram
временно скрыты (стоят заглушки) — сайт публикуется в открытом репозитории.

Заглушки в блоке «Контакты» (`index.html`, поиск по `[`):

| Заглушка | Что вписать |
|----------|-------------|
| `[ТЕЛЕФОН]` | номер телефона (в блоке «Контакты» и в подвале). Чтобы был кликабельным — верните ссылку: `<a href="tel:+7…">+7 …</a>` |
| `[TELEGRAM]` | ник в Telegram: `<a href="https://t.me/ник">@ник</a>` |
| `[WHATSAPP]` | ссылка на WhatsApp (или удалить строку `<li>` с WhatsApp) |
| `[EMAIL]` | адрес почты — в строке `<li>` с Email и в подписи под формой |
| `[ГРАФИК / СРОКИ]` | режим приёма заказов или ориентировочные сроки |

Когда появится e-mail — впишите его ещё и в `script.js`, строка
`var MAIL_TO = "[EMAIL]";`, чтобы кнопка формы открывала письмо на нужный ящик.

### 2. Форма заявки

Форма пока не отправляет данные на сервер — по кнопке открывается новое письмо
в почтовой программе посетителя. Варианты «по-взрослому»:
- подключить бесплатный сервис приёма форм (Formspree, Getform, FormSubmit и т. п.)
  — обычно нужно заменить `<form id="request-form" novalidate>` на их `action`;
- либо оставить как есть — многим достаточно письма / перехода в мессенджер.

|------|---------|------------------|

| `panda.jpg` | Ваза «Панда» для хранения | галерея |
| `bludca-nabor.jpg` | Комплект блюдец в цветочек | галерея + блок «Ресторанам» |
| `bludca.jpg` | Мини-блюдца в цветочек, крупно | запас (в галерее не выведено) |
| `ryba.jpg` | Керамическая рыба | галерея |
| `pitomcy.jpg` | Фигурки питомцев по фото | галерея |
| `rakovina.jpg` | Раковина с краном (в интерьере) | галерея (широкая плитка) |
| `rakovina-alt.jpg` | Раковина, кадр на светлом фоне | запас |
| `taro.jpg` | Набор керамических карт Таро | галерея |

Поменять снимок или подпись: в `index.html`, блок `<div class="grid-gallery">` —
у каждой плитки свой `style="--img:url('images/…')"` и текст в `<figcaption>`.
То же в блоках «Тарелка с вашим рисунком» и «Ресторанам»
(`<figure class="photo-frame" style="--img:url('images/…')">`). Если файл не
найдётся — покажется глиняная заглушка с подписью.

**Если будете переснимать:** формат JPG, 4:3 горизонтальные, ~1200×900 px,
до 300–400 КБ, один свет и настроение по всей галерее.

Отдельные фоновые изображения (не изделия):

| Где | Пропорции | Размер |
|-----|-----------|--------|
| Фон первого экрана в «Тёмном премиум» (`hero.jpg`) | 16 : 10, спокойное | 1920 × 1200 px |
| Фактура на фоне сайта в «Тёплом минимализме» (`texture.jpg`) | любые, ровная фактура | от 1600 px |

**Фон первого экрана в «Тёмном премиум» дизайне.** Уже установлено бесплатное
стоковое фото `images/hero.jpg` (руки за гончарным кругом, Pexels — свободная
лицензия, коммерческое использование, атрибуция не обязательна; источник указан
в `PHOTO-CREDITS.md`).

- **Поменять на свой снимок:** положите файл в `images/` и в `style.css` в блоке
  `[data-design="3"]` поправьте путь в строке `--hero-photo: url("images/hero.jpg");`.
  Подойдёт и светловатый кадр — сверху лежит затемняющий слой.
- **Вернуть рисованную текстуру без фото:** там же замените значение на
  `--hero-photo: var(--hero-fallback);` (это процедурный SVG, внешний файл не нужен).
- **Сделать темнее / светлее:** в правиле `[data-design="3"] .hero` измените
  прозрачность в `rgba(14,10,7, …)` — большее число делает фон темнее.

**Фактура на фоне всего сайта в «Тёплом минимализме».** Уже установлено фото
`images/texture.jpg` (зернистая глина, Pexels — свободная лицензия; источник
в `PHOTO-CREDITS.md`). Слой закреплён (`position: fixed`), не двигается при
прокрутке.

- **Поменять фактуру:** положите свой файл в `images/` и в `style.css` в блоке
  `[data-design="1"]` поправьте путь в строке `--site-photo: url("images/texture.jpg");`.
- **Убрать фактуру совсем:** там же — `--site-photo: none;` (останется ровный
  песочный фон).
- **Сделать заметнее / бледнее:** в правиле `[data-design="1"] body::before`
  измените прозрачность в `rgba(247,241,232, …)` — меньшее число = фактура заметнее.

### 4. Тексты

Все тексты — прямо в `index.html`, можно править как обычный текст. Проверьте
блоки «Тарелка с вашим рисунком», «Посуда под концепцию заведения», «Как проходит
заказ» — при желании подгоните формулировки под себя.

### 5. Портфолио на Авито

В блоке «Контакты» есть ссылка на профиль Авито. Проверьте, что адрес актуален:
`https://www.avito.ru/brands/23a82c1f3da20328be0f1d66113ceb50`.

## Проверка адаптива

Макет проверен на ширинах 375 px (телефон), 768 px (планшет) и десктопе.
Горизонтальной прокрутки нет, меню на телефоне скрывается, сетки перестраиваются
в одну колонку.

## Публикация онлайн (бесплатно)

Подойдёт любой статический хостинг, файлы заливаются как есть:
- **Netlify Drop** — перетащить папку на <https://app.netlify.com/drop>;
- **GitHub Pages** — запушить репозиторий, включить Pages в настройках;
- **Cloudflare Pages**, **Vercel** — аналогично.

Ничего собирать не нужно — это обычные статические файлы.
