# Приём заявок с формы → Telegram (через Yandex Cloud)

Форма на сайте отправляет заявку не напрямую в Telegram, а на облачную функцию.
Токен бота лежит в переменных окружения функции и в код/репозиторий не попадает.

```
Форма на сайте  ──POST──▶  Yandex Cloud Function  ──▶  Telegram API  ──▶  ваш чат
                          (хранит BOT_TOKEN, CHAT_ID)
```

## 1. Создать бота и узнать chat id

1. В Telegram напишите **@BotFather** → `/newbot` → задайте имя и username → получите **токен** вида `123456789:AAH...`.
2. Напишите этому боту любое сообщение (например «привет») — иначе он не сможет вам писать.
3. Узнайте свой **chat id**: напишите боту **@userinfobot**, он пришлёт `Id: 123456789`.

## 2. Развернуть функцию в Yandex Cloud

1. Зайдите на <https://console.yandex.cloud>, войдите через Яндекс ID.
2. Если облака ещё нет — создайте, привяжите платёжную карту (для проверки спишется и вернётся ~1 ₽; бесплатного лимита функций хватает с большим запасом: 1 000 000 вызовов в месяц).
3. В консоли: **Cloud Functions** → **Создать функцию** → имя `ceram8-form` → создать.
4. Вкладка **Редактор**:
   - Среда выполнения: **python312**
   - Способ: **ZIP-архив** или **Редактор кода**. Проще через редактор: создайте файл `index.py` и вставьте содержимое [`index.py`](./index.py) из этой папки.
   - **Точка входа:** `index.handler`
   - Таймаут: `10` секунд, память: `128 МБ` — достаточно.
5. Раздел **Переменные окружения** — добавьте:
   | Ключ | Значение |
   |------|----------|
   | `BOT_TOKEN` | токен от @BotFather |
   | `CHAT_ID` | ваш chat id (число) |
   | `ALLOW_ORIGIN` | `https://ceram8.ru` (можно `*`, если домен ещё не подключён) |
6. Нажмите **Сохранить изменения** — создастся первая версия.
7. Вкладка **Обзор** → включите тумблер **Публичная функция** (доступ без IAM-токена).
8. Скопируйте **ссылку для вызова** — вида
   `https://functions.yandexcloud.net/d4xxxxxxxxxxxxxxxxxx`.

## 3. Подключить к сайту

Отдайте эту ссылку — она подставляется в `script.js`:

```js
var FORM_ENDPOINT = "https://functions.yandexcloud.net/d4xxxxxxxxxxxxxxxxxx";
```

После этого кнопка «Отправить заявку» шлёт данные в функцию, а та — в ваш Telegram.
Пока `FORM_ENDPOINT` пустой, кнопка открывает письмо (`mailto`) как запасной вариант.

## Проверка

Заполните форму на сайте и отправьте — в течение пары секунд в чат с ботом придёт
сообщение «🧾 Заявка с сайта Ceram8…». Если не пришло — проверьте, что боту вы
писали первым (шаг 1.2) и что переменные окружения сохранены.

## Смена токена

Если токен «утёк» или бот спамит — в @BotFather: `/revoke` → выберите бота →
получите новый токен → впишите его в переменную `BOT_TOKEN` функции и сохраните.
Сайт трогать не нужно.
