# Ceram8 — сайт гончарной мастерской

Лендинг гончарной мастерской Ceram8 (Санкт-Петербург): тарелки и другая посуда
с рисунком заказчика для частных клиентов, разработка и брендирование посуды
для ресторанов и кафе, обжиг керамики в муфельной печи как отдельная услуга.

Чистый **HTML + CSS + немного JS**, без сборщиков, фреймворков и внешних
библиотек. Сайт открывается офлайн прямо из файла и работает на любом
статическом хостинге.

**Живая версия:** [ceram8.ru](https://ceram8.ru)
**Репозиторий:** приватный, `ckvo200736-cell/ceram8-site` на GitHub, деплой —
GitHub Pages.

## Структура

```
ceram8-site/
├── index.html                  Главная (лендинг, одна страница)
├── restoranam/index.html       SEO-страница «Ресторанам и кафе»
├── posuda-s-risunkom/index.html SEO-страница «Посуда с вашим рисунком»
├── privacy.html                Политика конфиденциальности (152-ФЗ)
├── style.css                   Все стили, одна активная концепция дизайна
├── script.js                   Меню, карусель отзывов, форма, цели Метрики
├── images/                     Фото изделий и фон первого экрана
├── serverless/form-endpoint/   Yandex Cloud Function — приём формы на почту/Telegram
├── concepts/                   Архив двух отклонённых дизайн-концепций
├── robots.txt, sitemap.xml     Индексация
├── yandex_788b84c5e005dfc1.html Файл-подтверждение Яндекс.Вебмастера
├── CNAME                       Домен для GitHub Pages (ceram8.ru)
├── .nojekyll                   Отключает обработку Jekyll на GitHub Pages
└── PHOTO-CREDITS.md            Источники и лицензии не своих фото
```

Три HTML-страницы (`index.html`, `restoranam/`, `posuda-s-risunkom/`)
самостоятельны и используют общие `style.css` / `script.js` по относительному
пути (`../style.css` из подпапок). У каждой — рабочая форма заявки, ведущая на
тот же облачный endpoint.

Как страницы связаны между собой:
- Из блоков «Тарелка с вашим рисунком» и «Ресторанам и кафе» на главной —
  кнопки «Подробнее» на соответствующие SEO-страницы.
- Из SEO-страниц — хлебные крошки и логотип назад на главную.
- В подвале каждой страницы — ссылки на обе SEO-страницы и на политику
  конфиденциальности.
- Обе SEO-страницы есть в `sitemap.xml`.

## Как запустить локально

Интернет не нужен — двойной клик по `index.html` открывает сайт в браузере
как обычный файл.

Либо через локальный сервер (нужно, если проверяете форму/фетчи или хотите
корректные относительные пути на SEO-страницах):

```
py -3 -m http.server 8000
```

и открыть <http://127.0.0.1:8000>. На этой машине команда `python` не
работает (см. ниже) — использовать `py -3`.

> На Windows здесь `python` — заглушка Microsoft Store и ничего не делает,
> нужно `py -3`.

## Как задеплоить

Сайт живёт на **GitHub Pages** с автодеплоем: любой `git push` в ветку `main`
репозитория `ckvo200736-cell/ceram8-site` выкатывает изменения на
[ceram8.ru](https://ceram8.ru) в течение минуты. Сборки нет — публикуются
файлы репозитория как есть.

```
git add -A
git commit -m "..."
git push
```

Настройки на стороне GitHub (менять только при переносе на новый аккаунт/репозиторий):
- Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/`.
- Custom domain: `ceram8.ru` (см. файл `CNAME`), Enforce HTTPS включён.
- На стороне регистратора домена (Beget) — A-записи на IP GitHub Pages для
  апекса и CNAME для `www`.
- `.nojekyll` в корне — обязателен, иначе GitHub Pages прогоняет файлы через
  Jekyll и может сломать пути с подчёркиванием/точкой.

Форма заявки шлёт данные в отдельный **Yandex Cloud Function** (не в этом
репозитории — код лежит в `serverless/form-endpoint/`, но разворачивается
вручную в консоли Yandex Cloud). Секреты (пароль почты, токен Telegram-бота)
хранятся только в переменных окружения функции, в коде сайта их нет. Подробная
инструкция по разворачиванию — в
[`serverless/form-endpoint/README.md`](serverless/form-endpoint/README.md).
